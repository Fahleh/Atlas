# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/Fahleh/Atlas/security/advisories/new)
feature rather than opening a public issue.

Include what you found, how to reproduce it, and its potential impact.
I'll acknowledge reports as promptly as I can and follow up once the
issue is understood.

## Scope

Atlas is a solo portfolio project, not a maintained production service.
Reports related to the application's own code, authentication, or
authorization (particularly Supabase RLS policies) are welcome. Reports
about third-party dependencies should go to those projects directly,
though flagging them here is still appreciated.

## Supported Versions

Only the latest release on `main` receives fixes.
