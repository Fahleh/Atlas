# Accessibility Component Audit

> Last updated: August 2026

This document is a component-by-component accessibility audit table. It is
not a pattern guide. For how and why each pattern is built the way it is
(dialog conventions, listbox conventions, focus trap scope, the dual
accessible/decorative usage of `Avatar`), see `docs/frontend.md`'s
Accessibility section.

Atlas targets WCAG 2.1 Level AA. Screen reader testing and a formal contrast
audit are tracked as open items in `docs/roadmap.md`, not claimed as done
here.

Add a row when a new component introduces a genuinely new interactive
pattern. A component that reuses an already-audited pattern (another
`role="alert"`, another `.srOnly` label, another `useFormStatus` submit
button) does not need its own row.

---

| Component | Semantic HTML | Keyboard | ARIA roles | Focus management | Status |
|---|---|---|---|---|---|
| `Sidebar.tsx` | `<nav>`, `<aside>` | Tab, Escape | `role="dialog"` (mobile), `aria-modal`, `aria-label` | Focus trap (mobile), scroll lock (mobile) | done |
| `Header.tsx` | `<header>`, `<button>` | Tab, Enter/Space | `aria-label` on burger | none needed | done |
| `ProjectCard.tsx` | `<div role="button">` | Enter, Space | `role="button"`, `aria-label`, `role="progressbar"` on the progress bar | none needed | done |
| `ProjectListTable.tsx` | `<table>`, `<th scope="col">` | Enter, Space on row-open button | `role="progressbar"` per row's progress cell | none needed | done |
| `ProjectStats.tsx` | `<dl>`, `<dt>`, `<dd>` | none needed | `role="progressbar"` on Tasks Done, `role="status"`/`aria-live="polite"` on the loading branch only | none needed | done |
| `ProjectSlideOver.tsx` | `<section>`, `<dl>`, `<ul>` | Tab, Shift+Tab, Escape (multi-guard) | `role="dialog"`, `aria-modal`, `aria-label` | Focus on open, focus trap, scroll lock | done |
| `TaskItem.tsx` | `<div role="button">` | Enter, Space | `role="button"`, `aria-label` | none needed | done |
| `TaskList.tsx` | `<ul>`, `<li>` | none needed | `aria-label` on list, `role="alert"` on error, `role="status"`/`aria-live="polite"` on the loading branch | none needed | done |
| `EntityModal.tsx` | `<form>`, `<label>`, `<input>` | Tab, Shift+Tab, Escape | `role="dialog"`, `aria-modal`, `aria-labelledby` (per-instance `useId()`) | Focus on open, focus trap, scroll lock (conditional) | done |
| `TaskModal.tsx`, `ProjectModal.tsx` | inherits `EntityModal` | inherits `EntityModal` | inherits `EntityModal` | inherits `EntityModal` | done |
| `StatusBox.tsx` | `<div role="listbox">` | ArrowUp, ArrowDown, Enter, Space, Escape | `role="listbox"`, `role="option"`, `aria-selected`, `aria-activedescendant` | Focus stays on listbox container | done |
| `Avatar.tsx` | `<img>` or text span | none needed | `alt` (content usage) or `aria-hidden` (decorative usage) depending on caller, see `docs/frontend.md` | none needed | done, context-dependent by design |
| Remove-member confirm buttons (`ProjectSlideOver.tsx`) | `<button>` (icon-only x2) | Enter, Space, Tab | `aria-label` on both (Cancel, Confirm) | Explicit `.focus()` on Cancel via `useEffect`, see `docs/decisions.md` | done |
| `ProfileForm.tsx` | `<form>`, `<label>`, `<input type="file">` | Tab, Enter/Space on Change photo button | `aria-label="Profile photo"` on the file input, `aria-label="Change photo"` on the trigger button, `role="alert"` on both error and success banners | Standard tab order, no trap (not an overlay) | done |
